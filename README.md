# contedalloca

Book / portfolio modello. Deploy da Vercel su **https://contedalloca.exagonagency.com**.

## Caricare il sito

- Pusha il sito sul branch `main`.
- Sito statico: `index.html` nella root. Progetto con build (Vite, Next, ecc.): la repo così com'è, Vercel riconosce il framework.
- Primo caricamento: la repo contiene solo questo README, si può sovrascrivere tutto (`git push -f origin main` va bene).
- Immagini, CSS e JS con percorsi relativi (es. `img/foto-01.jpg`); foto compresse (JPG/WebP).
