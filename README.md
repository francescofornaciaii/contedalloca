# contedalloca

Book / portfolio online su **https://contedalloca.exagonagency.com** (GitHub Pages, branch `main`, cartella root).

## Caricare il sito

1. Il file principale deve chiamarsi `index.html` e stare nella root: sostituisce il placeholder attuale.
2. Immagini, CSS e JS vanno nella repo con percorsi relativi (es. `img/foto-01.jpg`), mai percorsi del proprio computer (`C:\...`, `/Users/...`).
3. Da browser: **Add file → Upload files** → trascina i file → **Commit changes**. Limite 25 MB per file.
4. Il sito si aggiorna da solo in 1–2 minuti.

**Non cancellare** `CNAME` (collega il dominio) e `.nojekyll`.

## Note

- Foto: JPG/WebP compressi (lato lungo ~2000 px, idealmente sotto 500 KB l'una) per un caricamento veloce.
- DNS (GoDaddy, exagonagency.com): record CNAME `contedalloca` → `francescofornaciaii.github.io`.
